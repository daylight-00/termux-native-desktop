# Workflow experiments

This track contains workstation-level questions that are not part of the glibc runtime or GPU implementation itself, but directly determine whether the phone can function as a real development/research environment.

Current groups:

- `remote-development/` — Code OSS and remote-host workflow experiments.
- `python/` — user-facing Python environment workflow built around companion/interpreter results.

These experiments may depend on another workstream without belonging inside that subsystem's repository. The boundary is based on the question being tested, not only on which executable is involved.
