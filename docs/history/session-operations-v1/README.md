# Historical session-operations evolution

This directory preserves the changelog and design lineage of the former `docs/session-operations/` surface.

Current operational authority is under [`../../operations/`](../../operations/README.md). The old directory was retired after bundle-native initialization, repository-owned current state, handoff-free accepted boundaries, and optional non-authoritative checkpoints became established policy.

The changelog contains both superseded mandatory-handoff rules and the transitions that replaced them. Read it only to reconstruct why the collaboration model changed; do not apply older entries as current procedure.

- [`CHANGELOG.md`](CHANGELOG.md) — chronological process-rule evolution.
- [`../../handoff/README.md`](../../handoff/README.md) — archived narrative session-boundary records.
