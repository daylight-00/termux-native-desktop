
# Historical documentation

This index is for reconstructing chronology and earlier state. History is excluded from default onboarding.

| Need | Read |
|---|---|
| Transaction-level refactor/provider sequence | [`../refactor/README.md`](../refactor/README.md), then one named numbered record |
| Former session-boundary narrative | [`../handoff/README.md`](../handoff/README.md), historical use only |
| Broad chronological navigation | [`../timeline.md`](../timeline.md) |
| Git-level source transition | Git history from the supplied full bundle |

Historical records are preserved even when their interpretation, paths, branch names, or plans were superseded. Do not update them merely to make old text resemble the current architecture.

When a current task needs history, it must name the specific record and the question being reconstructed.
