## Current interpretation of system-foundation

The foundation series contains multiple lifecycles:

```text
01-05
    durable design source and target-model material

06-10
    historical assessment, migration strategy, roadmap, validation model,
    and open-question snapshot from an earlier repository state

11-12
    later reassessment and cross-document reconciliation that currently
    govern how the earlier material is interpreted
```

The series is not default onboarding material. A task should select a specific foundation document for a concrete design question.

## Consolidation boundary

The project currently has overlap among:

```text
PROJECT_CONTEXT.md
PROJECT_PRINCIPLES.md
system-foundation/01-05
system-foundation/11-12
AGENTS.md
```

This overlap is acknowledged rather than hidden. The next bounded task will consolidate the durable constitutional surface while preserving the original documents as design provenance. Until that transition is accepted, the links above remain canonical.
